Enroll a New Workstation into the Compute Pool

Install the Python agent daemon on any compute workstation or server host to volunteer its idle CPU/GPU power.

1. Clone agent repository on the volunteer PC:
git clone https://github.com/dccn/agent.git && cd dccn-agent && pip install -r requirements.txt
2. Start agent daemon with provider authentication:
python agent.py --name "Compute-Node-05" --email provider@dccn.network --password provider123

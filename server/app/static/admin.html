Enterprise Role-Based Access Control (RBAC) Hierarchy

Strict role separation enforced cryptographically at the JWT layer, FastAPI dependency guards, and client routes.

Administrator (Governance) admin

Superuser with universal authority across the entire compute network.

  • Approve, drain, and decommission compute nodes
  • Promote/demote user roles and toggle account status
  • Directly allocate or grant virtual compute credits
  • Inspect all global workloads & terminal logs
  • Access deep real-time system analytics
Compute Client (Workloads) compute_user

Workload submitter requesting cluster vCPU, RAM, and GPU resources.

  • Submit containerized workloads with resource requirements
  • Inspect 7-factor placement explanations for own jobs
  • Dispatch workloads and stream terminal execution logs
  • View personal compute credit balance and top up
  • Strictly barred from managing cluster nodes
Compute Provider (Hardware Host) compute_provider

Supplies physical or virtual compute nodes to the shared network.

  • Enroll host machines into the cluster fleet
  • Run Python node agent daemon with live telemetry
  • Toggle node drain state for scheduled maintenance
  • Earn 85% compute yield rewards from executed jobs
  • Strictly barred from approving nodes or other users

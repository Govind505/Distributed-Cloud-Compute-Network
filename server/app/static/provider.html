Enroll a Compute Node

Install the Python agent daemon on any physical or virtual compute host to volunteer its CPU/GPU capacity to the network.

1. Clone agent code on the compute host:
git clone https://github.com/dccn/agent.git && cd agent && pip install -r requirements.txt
2. Run agent daemon with your provider credentials:
python agent.py --name "Compute-Node-05" --email provider@dccn.network --password provider123
